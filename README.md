# Ejercicio de control de ventas

Una tienda de tecnologia desea llevar un control de ventas de sus productos. El dia de hoy lanzo una promocion en la que sus tres productos principales seran los que estaran disponibles. Quiere saber cual producto es el mas vendido (entre esos tres) solo registrando las primeras 20 compras

Desarrollar un algoritmo que permita dar solucion a la situacion planteada

Listado de productos:
- Xiaomi 18 Fold
- iPhone Duo
- Samsung galaxy Fold 8
